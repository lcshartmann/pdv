# Receipt Preview Scripts

These scripts help you preview ESC/POS receipt binary files written by the `FileAdapter` printer driver.

## Prerequisites

- Node.js (already installed with the project)
- Receipt binary files generated by `PrinterService` in `~/Documents/pdv/receipts/`

## Scripts

### 1. `parse-receipt.js` — Plain text output

Strips ESC/POS control codes and produces a clean `.readable.txt` file.

```bash
node scripts/parse-receipt.js ~/Documents/pdv/receipts/receipt-2024-06-08T20-30-15-123Z.txt
```

Output: `receipt-2024-06-08T20-30-15-123Z.readable.txt`

### 2. `render-receipt-html.js` — HTML preview

Generates a styled HTML file that looks like a real 80mm thermal receipt.

```bash
node scripts/render-receipt-html.js ~/Documents/pdv/receipts/receipt-2024-06-08T20-30-15-123Z.txt
```

Output: `receipt-2024-06-08T20-30-15-123Z.html`

Open the HTML file in any browser. It uses a 400px wide card with monospace font to simulate the thermal printer look.

## Quick workflow

```bash
# After completing a sale (which triggers printReceipt)
# 1. Find the latest receipt
ls -la ~/Documents/pdv/receipts/

# 2. Render it as HTML
node scripts/render-receipt-html.js ~/Documents/pdv/receipts/receipt-2024-06-08T20-30-15-123Z.txt

# 3. Open in browser
xdg-open ~/Documents/pdv/receipts/receipt-2024-06-08T20-30-15-123Z.html
```

## Limitations

- **QR codes**: The ESC/POS QR code command is skipped. The HTML output will show "Consulte esta venda pelo QR Code" but won't render the actual QR code image.
- **Formatting**: Bold, alignment, and font size commands are stripped. The HTML uses basic styling (center alignment for headers, bold for totals) but doesn't perfectly replicate the printer layout.
- **Barcodes**: Barcode commands are skipped.
- **Images**: Any image/bit-image commands are skipped.

These scripts are for **development preview only**. For production, use the real `escpos` printer driver.
